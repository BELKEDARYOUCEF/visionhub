Capacités

Les fonctionnalités

Ce que Lumen sait faire, du classement local jusqu'à la synchronisation cloud.

Glisser-déposer

Déposez une vidéo sur une playlist depuis la barre latérale. Classement en direct, anti-doublon.

Classement intelligent

Catégorie et playlist suggérées d'après le titre, les tags et la source de chaque vidéo.

Lecteur robuste

Miniature d'abord, iframe au clic, bouton « Ouvrir sur YouTube ». Fini l'erreur 153.

Recherche & filtres

Titres, tags, catégories, descriptions. Filtres par périmètre, source, playlist et tri.

Export XML

Toutes les modifications restent locales puis s'exportent en XML propre. Vos données restent vôtres.

Sync cloud · Phase C

Comptes Supabase, sauvegarde multi-appareils, et fonctionnement hors-ligne préservé.

Construction

La roadmap, tâche par tâche

13 tâches indépendantes, en trois phases. Du design local jusqu'au cloud sécurisé, sans jamais casser l'existant.

PHASE A
Design
Local, statique
A1Renommage VisionHub → Lumen, avec migration douce des données.
A2Design system — nouveau styles.css, palette violet-cyan, typo Sora + Inter.
A3Page d'accueil animée — grille interactive à la souris, stats réelles.
A4Dashboard Vidéos — sidebar, cartes, barre playlists, glisser-déposer.
A5Lecteur robuste + design appliqué à toutes les pages.
PHASE B
Fondations
Préparation cloud
B1Couche d'accès aux données unifiée, sans changer le comportement.
B2Modèle de données cible + schéma SQL Supabase (documentation).
PHASE C
Cloud
Comptes + sync
C1Connexion Supabase — SDK branché, mode local préservé.
C2Authentification — création de compte, connexion, session.
C3Tables + RLS — chaque utilisateur ne voit que ses données.
C4Migration locale → cloud, dédupliquée et idempotente.
C5Synchronisation local ↔ cloud, sûre hors-ligne.
C6Finitions — sécurité, accessibilité, tests, documentation.
